# The Odin Project - Calculator Project

A calculator application which was completed as part of The Odin Project curriculum.

The calculator can function with both button press input via the mouse, or can work with keyboard inputs. The keyboard inputs are as follows:

| Button           | Function                                                       |
| ---------------- | -------------------------------------------------------------- |
| 0-9              | Enters the corresponding number into the calculator            |
| +, -, /, *, ^, = | Enters the corresponding operator into the calculator          |
| .                | Enters a period into the calculator                            |
| <Delete>         | Corresponds to 'AC'; i.e., clears everything in the calculator |
| <Enter>          | Corresponds to '='                                             |
| <Backspace>      | Corresponds to <- on the calculator                            |

This was the first major project I've taken on. It has been a lot of fun making
this and working through The Odin Project so far!
